A program that writes one emoji that stands for this AI agent:

> 🔍

One character: a magnifying glass for an agent whose work is checking, verifying, and digging into the details before anything moves — instantly readable, specific to how the agent works, and far from the obvious robot or smiley.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the glyph above, no trailing newline, deterministic across runs.
